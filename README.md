# Belajar Bahasa Arab

Aplikasi web statis untuk belajar 28 huruf hijaiyah, kosakata, hadits, tajwid, fikih, serta kuis sederhana.

## Menjalankan

Buka `index.html` langsung di browser, atau gunakan GitHub Pages.

## GitHub Pages

Aktifkan Pages melalui:

**Repository → Settings → Pages → Build and deployment → Deploy from a branch → Branch: main / (root)**
